# GitHub 发布准备检查报告

日期：2026-10-25。版本：0.1.0。范围：从个人本地图谱整理出的独立发布目录，不修改正在使用的个人版本。

## 结论

原始个人目录不宜直接上传：它包含真实笔记与节点标识、私有快照/缓存和机器专属路径。当前发布准备版已将这些内容剥离，提供配置、虚构演示、可安装 Python 包、固定样例测试与 CI 配置。

这是**发布准备与功能检查**，不是完整的安全审计或所有平台的兼容性认证。GitHub 仓库尚未创建或上传；开源许可证没有替所有者决定，见 `LICENSE-NOTICE.md`。

## 验证结果

### 隔离测试

Python 3.12.15 下 `python -m unittest discover -s tests -v`：**7 项全部通过**。

1. JSON/脚本注入转义与模板占位符不被笔记文本二次替换。
2. 纯节点引用、字段/代码/自引用排除和循环父关系。
3. 同一个未打标签的子内容被 A、B 复用时，两篇引用各生成一次。
4. 非法矩阵、边端点与 NaN 不覆盖最近成功快照。
5. 配置占位值、非本机明文 HTTP 地址被拒绝。
6. 演示 HTTP/SSE、只传元数据、跨站 Origin 与非公开路径限制；演示不调用 MCP。
7. MCP 初始化、会话头和协议头、SSE 响应与只读工具限制。

### 浏览器

本机 Chrome 独立浏览器验证通过：5 个虚构笔记节点、5 个标签/字段结构节点、`#Note` 搜索、正文内跳转、缩放和暂停，无捕获的页面脚本异常。README 的截图来自虚构演示，不是个人图谱。

### 安装与资源

已构建正确命名的 `tana_local_graph-0.1.0-py3-none-any.whl`，在新建的 Python 3.12 隔离环境中以无依赖、无索引方式安装，再从临时目录启动演示；模板和 JSON 数据随 wheel 存在，HTTP 页面可访问。此前一次使用系统旧构建器产生的错误 `UNKNOWN` wheel 已弃用，未放入最终产物。

测试命中的是现有可用环境，不代表已经完成所有操作系统上的全新依赖解析。CI 配置使用 Python 3.11/3.13；GitHub Actions 尚未在仓库远端执行。

### 实际 Tana 只读核验

使用仅存在于本机临时进程中的现有连接配置，完成真实 MCP 初始化和工作区读取。向量数据库先用 SQLite 只读连接备份到临时目录，再运行公开版采集：得到 **29 个笔记节点、22 条关系**，与当时个人服务范围匹配，语义状态 ready；本轮新编码 0 篇（缓存命中）。

真实读取没有将工作区 ID、正文、token 或临时数据库保存到发布目录。此检查验证了当前 Tana 服务和现有缓存路径；未验证新下载模型、任意 MCP 服务或所有用户标签结构。

### 发布内容检查

- 原个人笔记/标签/字段/工作区标识的精确匹配扫描：未检出。
- 常见凭据格式、私有路径与运行文件规则扫描：通过；扫描器不承诺发现所有秘密。
- 项目默认配置只含占位符，不含有效凭据；运行缓存、模型、日志和个人配置被 `.gitignore` 排除。
- 不包含模型权重、虚拟环境、数据库、快照、历史 HTML 或私人审查记录。
- 个人服务的 HTML、采集器与 server 的 SHA-256 与开始整理时一致；未重启或改写个人服务。
- 打包使用显式路径清单，附带包内文件校验清单和压缩包 SHA-256。
