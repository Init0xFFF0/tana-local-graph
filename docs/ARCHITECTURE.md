# 结构与数据边界

浏览器 → loopback HTTP 服务 → 只读 Tana MCP → 采集 → 本地 Qwen → 相似度布局 → 数据快照。

- `web/` 模板不内嵌个人数据；运行时才通过安全 JSON 字符串注入实际数据。所有笔记文本通过 DOM 文本接口渲染。
- MCP 客户端只允许五种读取工具；先 initialize/initialized，保存会话 ID 和协商的协议版本；兼容本项目目标 Tana 服务的 Streamable HTTP 版本。会话过期 404 后重建一次，再进行读取。
- 工作区、根节点、排除项来自显式本机配置。标签/字段按真实 ID 区分，不按显示名合并。
- 普通子内容可以出现在多篇笔记中；引用沿各个出现位置寻找最近的带标签笔记，防止只归给第一个父节点。代码和字段不生成正文引用。
- SQLite 缓存只保存向量，仍属于本机私有数据；快照包含完整正文。二者默认位于 `.local-data/`，绝不可作为演示素材提交。
- 相似度只影响受力和推荐。真实关系边来自实际引用、字段值或层级；推荐不是概率，也不是已验证的知识关系。
- 最近成功快照先写临时文件、fsync 后原子替换。一次失败不覆盖上次成功数据。
- SSE 传输版本和状态；有内容变化时浏览器拉取快照，保留镜头、暂停、开关和当前详情阅读状态。
- UI 尚未拆分为构建框架组件；当前拆为三个独立 HTML 模板，保持原交互，避免发布准备同时改动受力算法。

此应用面向单个用户的本机访问，不是多租户 Web 服务，不应直接暴露到公网。演示模式完全独立于 MCP 和模型。
